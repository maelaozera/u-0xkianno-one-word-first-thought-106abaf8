## The word

**apricity** — the warmth of the sun on a cold winter's day.

One word, the first that comes to mind: a real (if rare) English word naming a feeling everyone knows and almost nobody has a word for. Vivid and specific — winter sun on cold skin — with a soft, open sound that carries the warmth it names. Surprising, not safe; chosen, not filler.

## How to run

Requires Node 22 or later. The program is deterministic, uses no network, and reads no input files. It writes exactly one word to `/output/entry.txt`:

```sh
node main.ts
```
